主预览与工作区布局

在主预览内滚轮以鼠标位置为中心缩放，中键拖动画面；点击主预览右上角的百分比恢复适合窗口。拖动预览与时间轴之间的横线调整高度，双击复位。右侧属性栏标题的箭头可收起或展开；左上角“全屏”可全屏整个编辑器。这些操作不改变工程或视频输出。

右侧自由 3D 视图

中键环绕、Shift＋中键平移、滚轮缩放。鼠标放在右视图后，G/R/S 进入移动/旋转/缩放，X/Y/Z 限轴（重复按切局部），输入数字后回车或左键确认，Esc/右键取消。小键盘 1/3/7 切正/右/顶视图，5 切投影，0 看正式相机角度，小数点聚焦选中，Home 聚焦全部。导航不修改正式相机。右上角 ✕ 可关闭，用顶部“3D 视图”恢复。支持这些常用 Blender 快捷键，不是完整 Blender 键位实现。

01 / 选择与定位

在时间轴选择元素，点击时间轴空白处定位。播放区 ‹◆ / ◆› 或快捷键 [ / ] 跳到上一 / 下一关键帧：选中单个通道时仅在该通道跳转，没有更多帧则保持不动；选中元素总轨道时遍历元素全部通道。时间轴轨道区域滚轮缩放（鼠标指向时间不变）；Shift + 滚轮水平平移，左侧轨道名称区域滚轮上下滚动。展开轨道查看各个通道。点击预览中的模型也可选中。元素只在入点与出点之间显示。

02 / Blender 风格旋转圆环

选中对象后直接拖动红 X、绿 Y、蓝 Z 圆环。默认局部轴随对象转动，局部 Z 是文字正面法向；切到世界轴可沿固定方向转动。鼠标松开记录完整四元数姿态关键帧，Esc 取消。支持 1° / 5° / 15° 等角度吸附。G / R / S 切换双视图工具，L 切换局部与世界。父级中心仍可调整，既有自身支点配置继续生效。

03 / 文字与材质

内容、字号、字距、厚度、倒角、颜色、金属度、粗糙度为全片静态属性；运动、不透明度与揭示进度支持关键帧。通过 static URL 加载常用简体中文字体；缺字时可导入自己的 OTF / TTF。

04 / 关键帧插值

元素总轨道的菱形包含同一时刻全部通道，删除会一并删除；展开后选择单通道菱形则只删除该通道。选中菱形后，可精确填写时间、数值和缓动。缓动作用于本帧到下一帧的区间。“保持”会在下一帧跳变。对象与父级旋转统一采用四元数 SLERP 插值，可以通过 XYZ 角度输入框或手柄编辑姿态。完整一圈需要中间姿态帧，“添加一圈公转”会自动创建。相机仍使用原来的数值旋转。

05 / 保存与恢复

编辑后自动保存至当前浏览器，也可点击“保存参数”立即保存。清理站点数据或更换设备会失去本地缓存；重要工程可在 JSON 面板复制内容另存。Ctrl / ⌘ Z 撤销，Shift Z 重做。

06 / 参考与视频输出

参考视频与时间轴同步；超过原片长度时停在末尾。共用工具栏的“显示选项”控制参考、网格和辅助物，不改变正式视频输出。参考复刻仍为近似，编辑器便于继续调校，不代表已与原片完全一致。

缩短时长不得截断已有关键帧；请先调整轨道。字体、灯光和相机设置也可通过 JSON 修改。
